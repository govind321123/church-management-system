# Church Management System

A web-based Church Management System developed using Python and Django to manage church operations, member records, certificates, financial activities, and reports.

## Features

* Member Management
* Birth Certificate Records
* Death Certificate Records
* Financial & Expenditure Tracking
* Household Management
* Spiritual Reports
* Church Administration Dashboard
* CRUD Operations
* Responsive User Interface

## Technologies Used

* Python
* Django
* HTML
* CSS
* JavaScript
* SQLite
* Bootstrap

## Project Structure

* Member Management Module
* Certificate Management Module
* Financial Management Module
* Reporting Module
* Authentication System

## Installation

```bash
git clone https://github.com/govind321123/church-management-system.git

cd church-management-system

pip install -r requirements.txt

python manage.py migrate

python manage.py runserver
```
